Interface – Prototype version

How does this prototype version work?

Our variables are:

  • h: Total rise or lift
  • β: Total angle of the rise interval (In this version, this value is fixed at 90°)
  • θ: Current camshaft angle, 0≤𝜃≤360°

The user supplies a value of h as input, chooses an algorithm, and the program calculates the SVAJ functions that define the motion of the cam follower.


Outputs

In the Outputs section, the user is able to download the SVAJ diagrams as an *.jpg image, as well as an *.xlsx file containing the information that was used to plot the diagrams for the full interval.


The user can also visualize the maximum values of velocity, acceleration, and jerk achieved under this scheme.
